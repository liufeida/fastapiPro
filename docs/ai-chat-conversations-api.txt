========================================
AI Chat Conversations 接口文档
========================================

基础路径: /api/v1/conversations
统一响应格式: { code: 200, message: "", data: ... }


----------------------------------------
1. 创建新会话
----------------------------------------
POST /api/v1/conversations

Request Body:
{
  "title": "我的新项目",
  "model_code": "deepseek-r1",
  "user_id": "user_001"
}

字段说明:
- title       string  可选  不传则自动用首轮对话前 30 字符做标题
- model_code  string  可选  会话当前使用的模型，允许后续切换
- user_id     string  可选  用户标识

Response (200):
{
  "code": 200,
  "message": "",
  "data": {
    "id": "4a3f9b2c1d5e6f7890abcdef12345678",
    "user_id": "user_001",
    "title": "我的新项目",
    "model_code": "deepseek-r1",
    "is_deleted": false,
    "created_at": "2026-08-08T10:30:00+08:00",
    "updated_at": "2026-08-08T10:30:00+08:00"
  }
}

备注: 前端可以不调这个接口 — 直接调 POST /api/v1/ai/chat/stream 不传 conversation_id，后端会自动创建。


----------------------------------------
2. 分页查询会话列表
----------------------------------------
GET /api/v1/conversations

Query Params:
- page      int     可选  默认 1
- pageSize  int     可选  默认 20
- user_id   string  可选  按用户过滤
- keyword   string  可选  按会话标题模糊匹配

Response (200):
{
  "code": 200,
  "message": "",
  "data": {
    "records": [
      {
        "id": "4a3f9b2c1d5e6f7890abcdef12345678",
        "user_id": "user_001",
        "title": "我的新项目",
        "model_code": "qwen-max",
        "is_deleted": false,
        "created_at": "2026-08-08T10:30:00+08:00",
        "updated_at": "2026-08-08T11:05:00+08:00"
      }
    ],
    "total": 15,
    "page": 1,
    "pageSize": 20,
    "pages": 1
  }
}

排序规则: updated_at DESC (最近活跃的排前面)
注意: conv.model_code 是"最近一次使用的模型"，不代表整个会话全程用的模型。会话详情里每条消息有自己的 model_code。

- tool_call_id      string|null tool 消息关联用，预留
- tool_calls        object|null assistant 发出的 tool_calls JSON，预留
- model_code        string|null 产生这条消息的模型编码，每条独立记录
- tokens_input      int|null   输入 token 数
- tokens_output     int|null   输出 token 数
- created_at        string     ISO 8601 时间戳
- attachments       array      该消息挂载的附件列表，user 消息可能有


----------------------------------------
4. 重命名会话
----------------------------------------
PATCH /api/v1/conversations/{conv_id}

Request Body:
{ "title": "重命名后的标题" }

Response (200):
{
  "code": 200,
  "message": "",
  "data": {
    "id": "4a3f9b2c...",
    "title": "重命名后的标题",
    "model_code": "qwen-max",
    "is_deleted": false,
    "created_at": "2026-08-08T10:30:00+08:00",
    "updated_at": "2026-08-08T11:10:00+08:00"
  }
}


----------------------------------------
5. 删除会话
----------------------------------------
DELETE /api/v1/conversations/{conv_id}

说明: 软删除，数据仍在 DB 中，列表不再返回、详情返回 404。

Response (200):
{ "code": 200, "message": "", "data": { "deleted": true } }


========================================
与 AI Chat 接口的联动
========================================

会话 ID 在 AI 流式接口的 SSE start 事件中返回:

  POST /api/v1/ai/chat/stream  (Form-data)
    model=deepseek-r1
    prompt=你好
    (不传 conversation_id)

  → SSE: event: start
    data: {
      "request_id": "...",
      "model": "deepseek-r1",
      "conversation_id": "4a3f9b2c1d5e6f7890abcdef12345678",
      "thinking": false,
      "enable_search": false
    }

前端拿到 conversation_id 后存入 URL (如 /chat/4a3f9b2c)。
下一轮对话把 conversation_id 传回去，允许切换模型:

  POST /api/v1/ai/chat/stream
    conversation_id=4a3f9b2c...
    model=qwen-max            ← 允许不同模型
    prompt=换个模型试试

后端自动把历史消息 (含 deepseek-r1 的输出) 作为上下文传给 qwen-max。
每条消息的 model_code 独立记录。


========================================
conv.model_code vs msg.model_code 语义区别
========================================

- 会话级 conv.model_code:  最近一次使用的模型，每次 chat/chat_stream 时自动更新
- 消息级 msg.model_code:   产生这条消息的模型，每条独立记录

前端可以:
- 侧边栏会话列表用 conv.model_code 显示 "最后使用: Qwen"
- 每条消息气泡旁用 msg.model_code 显示小标签 "DeepSeek" / "Qwen"
